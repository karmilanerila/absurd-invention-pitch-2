Entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/c/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty on make.fun.

## The pitch

The CrumbCourt 9000 hauls every toast crumb before a tiny tribunal and sentences the guiltiest crumb to sweep the counter clean before breakfast is allowed to begin.

## How it works

`main.py` (stdlib only) writes the single-sentence pitch to `/output/entry.txt`, honouring `MAKEFUN_OUTPUT_DIR`, writing directly with `open("wb")` and `chmod 0644` — no temp files, no network.

Run it:

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
